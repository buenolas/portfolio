# lucas-bueno-portfolio

Pagina de portfolio profissional de Lucas Bueno, desenvolvedor focado em backend, automacoes, dados e IA aplicada.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Rodando localmente

```bash
npm.cmd install
npm.cmd run dev
```

Acesse `http://localhost:3000`.
